01

浏览计划

留一点时间给好奇心，让丛雨在你设定的范围里探索。

兼容分区参考：4 游戏、36 知识、188 科技、160 生活、211 美食。站内分类可能变化，需核验所选分区实际返回的内容。留空时不做一般探索，明确委托仍可搜索。

主动评论与接话

决定怎样参与讨论，模型也可以选择静静旁观。

自主浏览开启且处于时段内才运行。模型可评论视频，同时对一条真实评论接话，也可保持沉默。只回复实际读取的评论，视频评论与评论区接话分别去重，共用发送额度和审核流程。被 @ 或被回复的通知不受这两个主动开关影响。

兴趣互动

对喜欢的内容表示赞赏，所有互动遵循统一额度。

是否感兴趣由模型根据内容判断；不评论也可以点赞。投币前检查余额与已有投币数，余额不足 1 枚或已经投过时跳过。互动共用每日发送总额度和间隔，全部人工模式下也会进入草稿。

自主动态与择时私信

丛雨可以选择暂不开口，也可以在允许时段内安排稍后发送。初始关闭，使用下方保存按钮启用。

首期动态仅发文字；私信只发给绑定且互关的主人。待审与失败计划也占用当日生成名额，结果未知时停止该类新计划。修改这里的设置会取消旧的未发送计划。私信也需开启“接收与回复私信”。

尚未启用自主发布。

消息与账号

管理私信、代理与主人作品的互动方式。

主人也需互关。单向关注、粉丝、陌生人和关系查询失败时均不回复；发送前再次核验。首次启用只建立历史基线。

默认 B站、QQ、微信及常用图片域名直连；本机和局域网也始终直连。其他网址按规则判断。

HTTP 代理同时承载 HTTP / HTTPS；也可填写 socks5://127.0.0.1:7890。未命中规则的网址直连。规则首次下载经代理完成，随后使用本地缓存；更新失败保留旧规则。无代理服务时请关闭。管理台仍在本机 8766。

收件与并发

让不同会话同时思考，同一段对话保持顺序。

默认由同一次生成返回正文和能否发送。不通过、判断缺失或格式异常均交人工。互关、来源、字数、额度与发送间隔仍由程序检查。

默认读取 3 页，评论/@ 合并后最多接收最新 90 条，私信入口最多接收最新 90 条。超限显示警告，较旧消息不保证补回。一个 key 可供多个请求并发；同一会话和已绑定同一人的私聊按顺序处理。生成、审核与平台发布分别调度。

额度与回复长度

控制每天的节奏，也给每条回复留合适的空间。

每日发送总额度包含评论、私信、点赞、投币和转发；模型调用次数与发送次数分别计算。一条回复通常需要生成和审核两次模型调用。调高并发不会增加每日额度；平台发布遵守最小间隔。

图片与视频画面理解

用真实读到的图片，为回复补充依据。

需支持图片输入的模型；可在本地配置独立视觉服务。部分读取失败时只依据成功分析的图片回复，活动记录显示图片覆盖数量。视频结合标题、简介、可得字幕和不同时间的低清预览帧分析，不下载整段视频。取帧数同时受图片数上限约束；没有快照时退回文字，截图不代表完整观看或听过声音。

语气与表情

偶尔一个小表情，让文字多一点丛雨的温度。

评论优先使用账号可用的 B 站官方千恋万花表情包，可搭配 1 个颜文字，如 (*´▽｀*)。两者合计最多 2 个；私信可用颜文字或 Unicode 表情。不强制每条使用，严肃语境可以不用，随完整正文一起审核。

定时角色插画

发现喜欢的作品，仅在授权范围内分享。

图片转载授权、来源会话与 API Token 在本地配置。无授权时不转载图片。筛选会参考标题、标签和描述；不会假装已经理解图片细节。与评论共用发布模式和每日发送总额度。
