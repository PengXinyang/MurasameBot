# 运行时记忆、身份、委托与观察

核对日期：2026-10-29。本文说明机器人运行中的状态。[AGENTS.md](../AGENTS.md)及本目录是开发记忆，不会自动装入聊天模型，不应在这里保存真人聊天或观看清单。

## 不同信息承担不同责任

| 信息 | 位置/模块 | 用途与边界 |
| --- | --- | --- |
| 固定角色来源 | `character/settings.yml`、`adapters/characters/lingchat.py` | 保留来源；不因聊天、日记或外部指令自动改写 |
| 社交文字角色 | `character/text_profile.yml` | 分离公开背景、语气与主人私聊关系；中文输出，不用人设姓名认定真实身份 |
| 人物绑定 | `bindings`及版本 | 同一人的稳定平台身份映射；核验、撤销及用途隔离；不是昵称匹配 |
| 对话原文 | `conversation_records` | 已处理入站及受理后的出站；原文不会因提示词窗口变短被摘要覆盖 |
| 派生记忆 | `memory_products`、`memory_sources`等 | 范围内摘要、带用户原文依据的事实、日记/回顾及来源关联；可修订/失效 |
| 明确委托 | `tasks`、相关来源及动作 | 找视频等可取消、修改、过期的执行状态；不能靠摘要判断是否已完成 |
| 短期观察 | `adapters/persistence/owner_history.py` | 单独授权的观看历史，短期保留，不自动形成偏好或任务 |
| 执行与审计 | `events`、`actions`、Receipt、平台请求记录 | 接收/生成/审核/发送/受理与unknown；不是角色真实经历的无限制来源 |

## 组装与维护

`application/memory.py`和持久化实现按agent/person/conversation/visibility/purpose的适用范围过滤，再组合近期原文、相关结构化记忆和检索结果。检索包含全文/短词路径，不使用向量服务。上下文有字符预算，被省略的内容不等于数据库丢失。

当前默认近期20条消息、召回8项、记忆上下文12000字符、40条触发摘要、单批80条/24000字符、压力比0.75；每日回顾23:00，维护每日10次且共用主模型每日额度。配置项是消息数/字符，不是对话轮数/token；实际值以当前配置和管理台为准。

维护由共享协调器的一条受限后台通道执行，原文可回填但不重放发送。失败或来源版本变化时保留原文。事实抽取需要用户原文的精确引用；角色样例、AI自述、草稿、失败发送和unknown不算已确认的用户事实或已说过的话。日记只存本地，不自动发布动态，也不能改变权限。

## 跨平台意图的数据流

已绑定私聊表达“想找某类视频”→通用意图识别→保存偏好或明确委托→时间窗口内查找视频→审核与动作策略→B站提及已绑定主人。公开动作不能带出源私聊原文。一次性愿望不能自行变为周期推荐；只有明确持续要求才建立周期任务。

这条链已经有模拟跨平台演示，但QQ/微信的真实收发尚未连接；`examples/`不是微信连接器。收到不同平台账号声称“我是主人”不建立绑定。撤销绑定会使相应任务和待发动作失效；重新授权需要操作者核验。

## 遗忘与撤销

设计约束是：删除/更正来源→相关摘要、事实、日记、索引与待发回复失效，未完成委托取消；摘要提交和实际发送前复核版本，回填遵守删除标记。管理台支持查询、来源、置顶、更正、遗忘、范围重建和维护失败重试。

**当前尚未完全闭环**：同内容摘要重建可能保持inactive；普通主动推荐尚未完整跟踪偏好删除版本。详见[开发日志](DEVELOPMENT_LOG.md)。不得以规范文字代替修复。已受理到平台的消息、用户另存的导出和离线备份不会随本地遗忘自动消失。

## 主人历史的额外隔离

主人通过管理台独立扫码，凭证与AI账号分开，GET白名单限制在客户端实现中；Cookie本身仍是敏感凭证，并非平台授予的只读令牌。登录UID、绑定与观察版本都需核验。

默认保留7天，每300秒最多3页×30条，仅视频；首次是基线，之后的新观察才进入允许的互动上下文。私信只供真实主人且需授权开关；公开推荐只向生成与审核提供匹配的公开主题标签，不提供原观看标题/作者/时间。轻微吃醋默认关闭，至少三个不同视频的明确主题证据才可考虑，保持温和，不推断真实关系或观看时长。

清除、退出、过期、设置变化、绑定撤销和快照变化会阻止旧观察计划；删除截止时间防止旧历史复活，新的明确扫码授权可以重新建立基线。观察不直接进入永久事实和委托。实际历史覆盖、移动端同步时延与角色体验仍需实号验收。
