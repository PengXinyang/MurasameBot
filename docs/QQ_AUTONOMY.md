# QQ主动私聊与自主择时

2026-10-31：已编码主人QQ主动文字私聊。AI可以依据近期聊天、共同记忆、话题及适用的社交线索，选择现在发、稍后发或跳过。检查间隔不是固定发消息的时间表。本轮没有主动群聊、Qzone、主动发图或语音。

## 开启与查看

1. 保持NapCat登录，在管理台“运行概况 → 平台服务”启动QQ。纯QQ主动私聊无需启动B站；找B站视频仍需B站内容模块。
2. 打开“QQ → 私聊与消息 → 主动来找你聊聊”，开启并保存“QQ主动私聊”。该功能默认关闭，不因原B站主动私信已开启而自动启用。
3. 可调整允许时段、星期、检查间隔、安静时间、最短消息间隔、每日计划/判断额度及最大延迟。设置独立保存，不改B站自主动态/私信参数。
4. 同一区域显示最近一次判断、下次检查及已安排的计划时间；下方“QQ相关回复与投递”显示主动私信计划、审核状态、失败/取消原因及平台回执。计划不等于已发送；平台受理不等于客户端实际送达。

| 参数 | QQ默认值 | 含义 |
| --- | --- | --- |
| 允许时段 | 每天09:00–22:00 | 使用共同的timezone；可按星期修改，支持跨午夜时段 |
| 检查间隔 | 30分钟 | 有机会时判断要不要联系，不是每30分钟发一条 |
| 每日判断次数 | 32次 | skip也消耗判断额度，模型总额度仍共用 |
| 每日计划数 | 2条 | 生成的草稿、取消/失败计划也计入当日生成数 |
| 最短主动消息间隔 | 240分钟 | 实际发出及生成计划均受冷却限制 |
| 聊天后安静时间 | 60分钟 | 最近来信/受理回复及未合并来信会阻止打断 |
| 最多延后 | 120分钟 | AI返回有界延迟，且实际计划仍须在允许时段内 |

关闭或修改QQ主动设置会取消原QQ主动草稿/待发计划，重新开启不复活已取消计划。停止QQ平台服务保留持久队列，恢复后按原有效期、来源和权限检查处理。已在途HTTP请求无法撤回，unknown仍禁止自动重发。

本地配置对应独立`qq_autonomy`节，可只覆盖需要修改的字段：

```yaml
qq_autonomy:
  private_enabled: true
  private_daily_limit: 2
  private_idle_minutes: 60
  windows:
    - {start: '09:00', end: '22:00'}
```

修改配置本身不自动启动NapCat或未选择的平台服务；按[平台服务](PLATFORM_SERVICES.md)运行worker。默认不开启正式账号后台作为开发验证。

## 决策、记忆与发送

复用原`AutonomyService`，由唯一WorkerCoordinator的后台任务调用，不新增QQ角色循环、sender或微服务。装配层为各有能力的平台提供`AutonomyTarget`：平台/账号、独立策略、私聊开关和可选的入站活动检查。B站继续使用原autonomy配置与状态键，QQ使用qq_autonomy及独立状态/判断预算；快照、重复正文、计划额度与unknown待核查按平台隔离。两端仍共用模型总限额、来源版本、审核及全局串行发送。

QQ通过原主人绑定和OneBot好友/机器人身份核验确定目标，模型不能指定收件人。上下文探针只读取真实聊天与可召回记忆，不伪造主人来信。主人的QQ/B站私人聊天按现有共享记忆授权合并；其他人的私聊和公开对话继续隔离。B站授权观察仅在相应服务/授权有效时按原私聊用途提供，不被当作真实聊天或永久偏好。QQ允许按其私人语言策略自然混合语言，B站语言和公开限制保留。

AI的delay_minutes写入原Action.not_before，重启后可以续发，无需模型线程睡眠。生成不保证发送：同次审核缺失/拒绝进草稿；独立审核模式沿用原流程。发送前复验策略版本、绑定、记忆、来源、好友、暂停、时段和额度，只有受理输出才记为丛雨已说过的话。

QQ原始会话ID与主动消息使用同一平台规范化函数，避免主动消息读取另一条空会话。ChatBatches额外提供有效绑定/记忆版本下的活动快照：仍在30秒合并窗口的消息会阻止生成，并在真正写入前使旧开场失败；不会等到合并事件创建后才发现主人已输入。B站读取冷却/发送静默不阻塞QQ主动判断，QQ计划也不触发B站的专属读取静默。

## 验证边界

测试使用模拟OneBot/模型和隔离数据库，覆盖共享上下文、目标固定、好友失效、绑定/记忆变化、新合并来信、最终HTTP写入前竞态、审核、skip预算、unknown不重放、平台隔离、重启及配置取消。管理台使用隔离浏览器检查显示、保存、两端设置隔离和旧计划不复活。完整结果见[验证记录](VALIDATION.md)。实际主动话题是否自然、择时是否合适及客户端送达仍需运行后体验；本轮未启动正式账号常驻或执行真实主动发送。
