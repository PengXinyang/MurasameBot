# QQ空间自主说说与统一记忆

2026-10-31。使用[NapCat上游send_qzone_msg接口](https://github.com/NapNeko/NapCatQQ/pull/1965)发布好友可见的纯文字说说。本机现有NapCat安装包已只读确认含该接口；不代表当前登录、空间权限或真实发布已经验收。本轮不安装额外网关/插件，不执行真实发布。

## 开启与查看

重启管理台，在“QQ → 私聊与消息 → QQ空间·自主说说”开启并保存，保持NapCat登录及QQ平台服务运行。默认关闭；默认每天09:00–22:00可判断、30分钟检查、每日最多1条计划/8次判断、说说至少间隔360分钟、最多延后120分钟、正文300字，均可在页面调整。检查不是定时必发，AI可以skip。

空间策略使用独立qq_space配置；主动私聊继续使用qq_autonomy，B站继续使用autonomy。修改/关闭空间设置只取消旧空间草稿/待发计划，重新开启不复活，不取消QQ私聊或B站计划。状态和计划时间在空间区域，正文、审核、计划及回执在QQ动作列表；正式后台未为开发验收而开启。

固定使用ugc_right=4（好友可见），仅发文字；AI不能指定可见对象、附件、本地文件或链接。空间面向多位好友，仍按公开内容处理，不等于主人私聊。

## 一个AI、一套记忆

QQ私聊、B站私聊、B站动态和空间共用原数据库、MemoryService、记忆维护、角色、模型预算及outbox，不建立平台专属记忆库或第二个AI循环。

B站动态与QQ空间的同一个自主发帖调用现在包含：同一记忆库中可公开的近期记录/有有效公开来源的摘要事实、近期已受理的公开发言、当前时间、主题和程序筛选的角色状态。来源遗忘、记忆版本变化继续阻断旧生成。公开上下文不带私人聊天、私人日记/回顾或观看清单；私人线索只能沿用现有通用感受投影。已受理的空间/动态按原出处进入共同记忆，主人私聊也能回忆同一个AI已发出的两端公开文字。当前状况是实际提供的时间和有效线索，不假装知道天气、主人此刻活动或在线状态。

## 调度与协议

复用AutonomyService/AutonomyTarget，QQ空间使用单独dynamic目标，与QQ私聊private目标区分；原WorkerCoordinator负责择时，Action.not_before持久化，原审核及全局串行sender发送。发送前核对机器人身份、当前策略/记忆/暂停/时段和最终门禁，POST仅调用一次。成功必须得到确定tid；明确拒绝为failed，超时、无有效tid及不明确结果为unknown，不自动重放。只有accepted才进入已说过的话；受理不等于好友实际可见。

QQ空间不需要B站凭证；B站协议适配器不变。没有好友动态读取/评论/点赞、图文空间发布、空间独立可见性核查或浏览器发布兜底；旧网关缺接口时明确失败或unknown，不改用私聊发送。

## 验证

新增10项模拟回归覆盖共享公开上下文/私聊回忆、当前时间、私人排除、真实请求字段与确定回执、路由和最后门禁、审核草稿、unknown不重放、B站同链及设置隔离。另用隔离库验证公开派生事实进入上下文和来源遗忘后退出。管理台桌面/手机控件和保存隔离经真实无头Edge检查。完整结果见[验证记录](VALIDATION.md)；择时/文案质量和好友实际可见性仍待运行体验。
