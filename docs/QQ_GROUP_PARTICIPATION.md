# QQ群自主参与讨论

2026-10-31已编码；仅模拟验证，尚未启用正式群或进行实群发送。取代此前仅允许被@/引用时回复的开发范围，表达/黑话学习仍未实现。

## 开启与窗口

管理台「QQ → 私聊与消息 → QQ群 · 参与讨论」中，先配置允许群号、启用群聊，再打开「自主参与讨论」。保持现有QQ平台服务与NapCat运行，不增加群进程。默认自主开关关闭；关闭时保留原被动回复。

自主模式下，普通群文字也会推进讨论窗口，@/引用不再另外触发一次被动回复，避免双发。默认静默8秒后收集，持续刷屏最长等待30秒。上下文仍仅最近30条、30分钟，最多12000字，包含真实账号、群名片、消息号、时间、引用、可靠主人标记和已受理的自身发言；图片等仅作未分析占位。不获取整群历史，也不展开窗口外引用。

AI可返回skip，或选择窗口内一条最适合回应的真实群友消息，并返回该消息号和作者账号。程序必须同时匹配两者，拒绝窗口外用户、机器人自身、错配作者或缺失字段。发送时固定引用被选消息并提及该作者。AI选择较早发言者也可以，不默认回答最后一位；昵称和模型自称均不建立身份。

## 节奏、失效和记忆

默认每群至少60秒判断一次、滚动24小时最多100个判断窗口；skip也消耗该窗口额度。每群发送间隔和滚动24小时回复额度继续独立控制，另受共同全局模型预算、审核和串行发送间隔约束。额度统计持久化，重开群设置不清零已有判断用量。unknown发送阻断该群的下一次窗口判断，先人工核查，不能自动重发。

只有新的群友消息才产生新窗口；无新消息不定时重复找话题，自身回声不推进窗口。每群至多一个未处理窗口，同一窗口重试沿用同一动作ID。窗口创建后若收到新消息，无论正在生成还是已排队，旧窗口回复都失效；后续由新窗口重新判断，不强行补发。频繁刷屏时可能多次放弃旧回复，以避免接错话。

群号/机器人账号/配置/记忆版本及成员权限继续最终复验。配置变化清空临时窗口并取消旧群回复，记忆修订阻断旧输出，重启不重复处理已完成窗口，重复历史上报不会使新窗口变脏。原QQ私聊、空间和B站计划不受群设置取消影响。

同一个AI、数据库、协调器、模型服务、审核和outbox继续复用。普通群文字仅作有界缓存；窗口事件仅存调度定位信息，不保存一份原始群聊文本。被选中的回复来源与受理输出按group/group_dialogue归档，群上下文不会进入主人私聊、其他群或公开动态/空间；主人私人关系、观看与日记不注入群回复。自主参与不等同于语言学习或群内视频委托。

## 新增配置

在原qq_groups中新增以下字段，旧本地配置由默认值补齐：

```yaml
qq_groups:
  autonomous_enabled: false
  quiet_seconds: 8
  max_wait_seconds: 30
  decision_interval_seconds: 60
  daily_decision_limit: 100
```

调度窗口由原QQ模块poll_private钩子冲刷，沿用QQ轮询节奏，以上是最早可判断时间而非精确计时保证。没有配置正式群号，本次未擅自开启；需由用户在管理台选择部署范围。模拟测试见tests/test_group_participation.py及[验证记录](VALIDATION.md)，实群可见性、讨论节奏和措辞自然度仍待验收。
