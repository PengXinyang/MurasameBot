# QQ与B站视频委托联动

2026-10-30。实现QQ主人需求→持久视频任务→B站检索/内容理解→QQ文字链接或B站真实提及；模拟验证与实号验收分开。本节描述Q2编码阶段的模拟验证；后续经用户授权，本机NapCat已登录，实号检查单列在[验证记录](VALIDATION.md)，不与模拟结果混同。

## QQ私聊与公开投递的不同规则（2026-10-30用户调整）

QQ主人私聊及视频结果允许日语、英文、混合语言和视频原标题，不再强制纯中文。QQ私人找视频不受公开敏感/严肃话题筛选或公开分类缺失的限制；仍按真实取得的内容判断是否符合需求。敏感标记保留为来源/隐私信息，不再阻止私人任务执行。

平台模块声明私人策略；共享内核按目标私聊策略选择独立的只读内容入口，不复制QQ决策或记忆内核。B站适配器的公开搜索/读取默认保持原样，私有包装器显式关闭话题筛选；私人读取不会直接复用被公开筛选截断的缓存。审核收到同一私人策略，不因混合语言拒绝。

“在B站@我”等公开投递继续执行原话题及中文规则。主人/好友/目标绑定、来源版本、取消/遗忘、真实证据、内容长度、唯一可信视频链接、额度/时段和unknown不重试均继续生效。此调整不增加点赞、投币或公开评论副作用。

## 使用方式

| QQ中的表达 | 程序行为 |
| --- | --- |
| 帮我找摄影入门视频，发给我 | 一次性找视频，默认回到该主人QQ私聊 |
| 找摄影视频，发到QQ / 发这里 | QQ返回推荐理由与所选视频的可信链接 |
| 找摄影视频，在B站@我 / 艾特我 | 在所选视频下生成公开短推荐语和绑定主人提及 |
| 不想看了 / 不用找了 / 取消任务 | 取消最近有效委托及其未发结果；QQ简单取消可直接由程序识别 |
| 全部取消 / 都不想看了 | 取消当前主人的全部有效视频委托 |
| 换成夜景摄影的视频 | 验证新任务后取消旧委托与旧结果，保存新主题 |
| 每天推荐摄影视频 | 仅在明确持续指令下才设置周期；一句“想看”不会变成长期订阅 |

私聊原文不进入公开推荐生成或公开审核。明确同时指定两个投递渠道时要求澄清，不擅自双发；否定表达如“别@我，发到QQ”按否定后的渠道处理。目标账号来自已核验绑定，模型无法选择QQ号、UID或机器人账号。

QQ接入和主人绑定沿用[QQ私聊说明](QQ_PRIVATE_CHAT.md)。找视频是本轮完成的任务类型，不代表已经实现任意生活提醒、任意工具执行或替用户操作其他服务。

## 保存与执行

原`tasks`、记忆来源及任务状态机继续复用。新增附加表`task_routes`保存程序生成的内容来源平台、投递平台/模式、目标机器人/主人、源账号和绑定版本；旧任务没有该记录时保留原B站行为，不迁移或重放历史动作。

QQ任务默认从B站找内容，但结果投递平台可以是QQ。QQ回传不要求主人同时绑定B站；B站提及则必须存在允许提及的主人B站绑定。未启用来源平台或投递平台时保留任务，恢复后再执行，不把QQ当成视频搜索源。

明确QQ委托独立于“一般自主浏览”开关，关闭探索仍可执行；查找和投递继续遵守已配置的浏览时段、星期、到期时间、重试次数、全局暂停、模型预算与发布额度。到期前无合适内容则有限重试，不能承诺一定找到；默认全局发送间隔仍为10秒。定时要求由原意图抽取处理，QQ默认30秒静默合并行为不变。

QQ结果使用独立`task_result`动作：仅给绑定且为好友的主人，程序提供并核验视频URL，完整正文审核后才入队，发送前再次检查账号、好友关系、来源、任务/记忆与绑定版本。结果保留在私聊历史中；QQ结果和B站推荐共用每日推荐额度/冷却。查找QQ结果不会顺带发表评论、点赞或投币。

B站提及沿用既有生成、审核与适配器，程序完成真实用户提及，不只拼接一个外观像@的字符串。公开生成和独立审核只使用所选视频、允许的主题与推荐正文，私人委托原文不提供给公开审核。

## 取消与并发

- 任务状态与版本、来源记忆在SQLite持久保存，重启后恢复。记忆来源删除、绑定撤销、任务取消/修改会使旧结果失效。
- 取消覆盖查找中、待审核、排队和发送前门禁；人工批准不能绕过失效来源或已取消任务。已被平台受理的内容无法由本地取消自动撤回。
- 主人新QQ消息仍处于合并缓冲或事件队列时，既有委托结果暂缓领取；等新指令处理后再决定发送，避免取消消息尚在30秒窗口就先把旧结果发走。其他人的消息不阻塞主人委托。
- 最终写入前若又发现主人新消息，确认尚未写出的结果回到等待队列；若取消已经处理，则任务版本校验直接阻止发送。HTTP已经在途时不能保证撤回。
- 超时/回执未知保持unknown，不自动重发；“生成”“排队”“接口受理”“用户实际收到/公开可见”分别记录。

管理台“委托”显示任务；“私信”板块展示QQ委托结果、审核与回执。QQ回传与原公开评论的内容去重分开，避免一个曾评论过的视频无法再次应明确委托私下分享。
