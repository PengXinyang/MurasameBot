# QQ群被动接话

新增[自主参与](QQ_GROUP_PARTICIPATION.md)已实现，本文描述自主开关关闭时的被动模式。

2026-10-31：已编码并进行模拟验证，默认关闭；尚未配置正式群号或进行实群验收。自主插话、群聊节奏学习和黑话学习仍见[后续计划](QQ_GROUP_PLAN.md)。

## 使用方式

1. 让机器人账号加入目标群，保持NapCat登录、现有Array消息格式及签名HTTP上报。
2. 在管理台「QQ → 私聊与消息 → QQ群 · 参与讨论」填入允许的群号，打开开关并保存。群号只保存在本地覆盖配置中，不写入公开仓库。
3. 在管理台启动QQ平台服务，保持共同工作循环运行。已经运行时无需新增独立群聊进程。
4. 在指定群中直接`@丛雨`，或引用丛雨发出的群消息并附上文字。普通群聊和`@全体成员`仅提供近期语境，不触发模型。

默认上下文为最近30条、30分钟；每群回复至少间隔30秒，每群滚动24小时最多100条，单条最多400字。还受共同模型预算、暂停、审核、总发送额度及全局发送间隔约束。间隔或额度不足时本次回复跳过，不在冷却后补发。模型也可以选择不回复；审核拒绝或不可用按原流程转草稿。

群聊直接进入持久事件队列，不使用主人私聊的30秒静默合并窗口。首期一次触发生成至多一条文字回复，发送时引用本次来信并提及其发言者。可以自然使用外语，不开放模型指定群号、收件人、链接或额外工具任务。

## 对象与上下文

真实`user_id`识别发言者，群名片/昵称只用于显示；只有已有有效绑定认定主人。模型分别获得回答对象、引用消息作者和按时间排列的近期消息，不能把引用作者、相邻发言或昵称当成本次回答对象。引用查找必须同时核实群类型、群号、消息号及作者，缺失字段或跨群/私聊引用不展开；无法核实引用时也不会仅凭引用触发。直接@仍可处理，但会明确缺少引用资料。

上下文按同一agent、机器人账号和群隔离，只包含启用后实际收到的消息及本群已受理的自身回复；不拉取整群历史。原消息保留作者、消息号、@和引用信息。图片/表情/语音等仅作「未分析」占位，首期不会下载或调用视觉。匿名/系统消息、自身发送回声及未授权群不会进入群收件。

普通消息仅作有界缓存，不逐条调用模型或保存为长期档案。触发消息及平台已受理的回复进入现有共同记忆库，标记`visibility=group`、`purpose=group_dialogue`，管理台能查看群号、发言者和正文；共同记忆页保留来源与遗忘。群原文不会提供给主人私聊、其他群、B站动态或QQ空间，主人私聊/观看/日记及私人关系设定也不注入群聊。此功能未接入长期群知识检索、自动黑话学习或群内视频委托。

## 发送与失效

复用原签名回调、唯一WorkerCoordinator、模型并发/预算、审核及outbox。适配器只负责OneBot协议，群聊服务与有界上下文仓储分别独立，B站协议不变。每次发送复查当前群配置、机器人身份、机器人和目标的群成员身份、已知个人禁言、记忆版本及来源。群整体禁言、机器人权限不足等仍可能由服务端拒绝，不把成员检查当作发送成功证明。

修改群设置会清空临时群上下文、取消旧待发群回复；不取消QQ私聊、空间或B站计划。删除来源/记忆变化会阻断旧输出，记忆修订同时清空临时群上下文，已遗忘回复的引用不重新从远端载入；已受理的历史档案不会因关开设置而伪装成新近上下文。重启保留尚有效的缓存和事件，重复上报不重复生成/发送；旧上下文过期后不回复。缓存按窗口逻辑过滤，收到新消息时清理过期行；长期档案遵循共同记忆管理，不等同于30分钟自动删除。

明确失败记录失败；缺少确定消息号或超时记录`unknown`，不会自动重发，且阻断该群后续回复，需先人工核查原记录。平台受理不证明群内可见。首期未接入群撤回通知，不能保证即时获知所有撤回；可在共同记忆中手动遗忘已归档的触发来源。

## 配置与验证

本地配置对象`qq_groups`：

```yaml
qq_groups:
  enabled: false
  group_ids: []
  context_messages: 30
  context_minutes: 30
  cooldown_seconds: 30
  daily_reply_limit: 100
  max_characters: 400
```

协议依据为[OneBot群消息事件](https://github.com/botuniverse/onebot-11/blob/master/event/message.md)及[公共API](https://github.com/botuniverse/onebot-11/blob/master/api/public.md)。NapCat的`get_msg`若没有提供可确认的`group_id`，引用单独触发会拒绝，可使用直接@。

新增测试见`tests/test_qq_groups.py`，覆盖模拟OneBot、真实应用/SQLite、签名回调和群范围；另核对1440/390宽管理台。结果见[验证记录](VALIDATION.md)。实群需另行确认机器人已入群、直接@与引用均可收到、回复提及正确用户、普通闲聊不触发；当前模拟结果不能代替这些验收。
